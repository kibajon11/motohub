# 🏍️ MotoHub

**MotoHub** — это онлайн-платформа для поиска, просмотра и заказа деталей к популярным мотоциклам (Honda, Yamaha, Kawasaki).  
Проект строится на **Next.js + Tailwind CSS** с загрузкой данных о моделях и деталях из **Excel-файлов (XLSX)**.  

---

## ✨ Возможности
- 📊 Импорт моделей и деталей из Excel (годы выпуска, категории, запчасти)  
- 🖼️ Категории и детали с фотографиями и характеристиками  
- 🛒 Корзина с учётом стока и блокировкой кнопки «Добавить» при отсутствии товара  
- 📱 Современный адаптивный дизайн (удобно и на телефоне, и на компьютере)  
- ☁️ Лёгкая интеграция с Cloudinary для хранения изображений  

---

## 📂 Структура проекта

```
motohub/
├─ app/                 # Страницы Next.js
│  ├─ [brand]/          # Динамические страницы брендов
│  ├─ api/              # API-роуты (чтение Excel)
│  └─ page.js           # Главная страница
├─ components/          # Повторно используемые компоненты (Header, Cards и т.п.)
├─ public/              # Статика (картинки, placeholder.png, data/*.xlsx)
├─ styles/              # Глобальные стили Tailwind
├─ package.json         # Скрипты и зависимости
└─ README.md            # Этот файл
```

## 🚀 Запуск проекта локально

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск dev-сервера
```bash
npm run dev
```

### 3. Очистка кеша + запуск (удобный скрипт)
```bash
npm run clear
```
